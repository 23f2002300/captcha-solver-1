# Captcha Solver Demo This project provides a simple, client-side web application designed to demonstrate the basic UI for a CAPTCHA challenge and a placeholder for a "solver" mechanism. It can display CAPTCHA images either from a local file (`sample.png`) or from a remote URL provided via a query parameter. Users can input their interpretation of the CAPTCHA, and for the local sample, a basic verification is performed. ## Features *   **Dynamic Image Loading:** Loads CAPTCHA images from a `url` query parameter or defaults to `sample.png`. *   **User Input Field:** Allows users to enter their CAPTCHA solution. *   **Basic Verification:** For the `sample.png` image, it checks if the entered text matches "ADCRB". *   **Responsive Design:** Built with Tailwind CSS for a modern, mobile-friendly interface. *   **Single-File Application:** Easy to deploy and run. ## How to Use 1.  **Clone the repository (or save the `index.html` file):** ```bash git clone <repository-url> cd captcha-solver-demo ``` (Or just copy `index.html`, `README.md`, `LICENSE`, and `sample.png` into a directory) 2.  **Open `index.html` in your web browser.** *   **To use the default `sample.png`:** Simply open `index.html`. *   **To specify a custom CAPTCHA image URL:** Append a `?url=` query parameter to the URL in your browser. Example: `file:///path/to/index.html?url=https://example.com/some-captcha.png` (Note: Due to CORS policies, loading images from different origins might require the remote server to send appropriate CORS headers, or you might need to run this on a web server.) 3.  **Enter the CAPTCHA text** in the input field and click "Verify Captcha". ## Technology Stack *   **HTML5:** For the core structure. *   **Tailwind CSS:** For styling and responsive design. *   **JavaScript:** For dynamic content loading and client-side logic. ## License This project is open-sourced under the MIT License.
